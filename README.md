# 💡 Tips for Awesome Designs

- **Save often.** TinkerCad saves for you, but check that your design has a name you'll recognize.
- **Start simple.** Build with basic shapes first, then add the fun details.
- **Think about printing.** Very thin or very tiny parts can break. Make things a little chunkier than you think you need.
- **Undo is your friend.** Made a mistake? Press `Ctrl + Z` (or `Cmd + Z` on a Mac).
- **Ask 3 before me.** Stuck? Try to figure it out yourself, then ask a neighbor, then a tutorial, and then ask me! I'm always happy to help.
- **Failed prints happen.** Even experts have prints that go wrong. We just learn from it and try again. 🔁
